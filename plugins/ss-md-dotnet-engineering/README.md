# ss-md-dotnet-engineering

Skills collection. Highly opinionated support in the areas of 
- .NET solution standards
- syntax
- refactoring
- domain-driven design
- clean code
- declarative coding
- performance optimization

Inspired by core literature incl. 
- Domain-driven design (Eric Evans)
- Clean Code (Robert C. Martin)
- Refactoring (Martin Fowler et.al.)
- Functional Programming in C# (Oliver Sturm)
- High Performance .NET (Armen Melkumyen) 

Support for functional (declerative) programming focuses on harnessing existing .NET's features without introducing 3rd party functional programming libraries, to create more expressive code.

See the [repository installation guide](../../README.md) for supported clients and marketplace setup.

The plugin does not change editor settings or enforce guidance deterministically. Use the actual skill names exposed by your client. Existing project instructions and verification requirements still apply.

Maintain the files in this directory directly, keeping local reference links within each skill directory.
